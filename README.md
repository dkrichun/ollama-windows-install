# Ollama для Windows — Установка, Обновление и Удаление

Комплект скриптов для развёртывания и обслуживания [Ollama](https://ollama.com) на Windows в виде службы через [NSSM](https://nssm.cc). Оптимизирован под **NVIDIA RTX 4060 (8 ГБ VRAM)**, но работает на любом железе с подстройкой INI.

## Состав комплекта

| Файл | Назначение |
|---|---|
| `ollama-windows-install.ini` | Единый конфиг (пути, сеть, модели, производительность) |
| `ollama-windows-install.ps1` | Установка, обновление, переустановка и логирование |
| `ollama-windows-uninstall.ps1` | Удаление службы и очистка |
| `README.md` | Этот файл (документация) |

Все четыре файла должны лежать в одной папке — например, `D:\AI\Ollama\install`.

---

## ⚙️ Параметры запуска `ollama-windows-install.ps1`

Скрипт установки принимает следующие ключи:

| Ключ | Описание |
|---|---|
| `-ConfigPath <string>` | Путь к нестандартному INI-файлу. По умолчанию ищет `ollama-windows-install.ini` рядом со скриптом. |
| `-Force` | Отключает все интерактивные запросы (подтверждения, меню выбора версий). |
| `-ForceDownload` | Принудительно скачивает дистрибутивы заново, игнорируя локальный кэш в папке `Downloads`. |
| `-Upgrade` | Режим тихого автообновления. Принудительно включает `-Force`, выбирает последнюю версию (`latest`), отключает интерактивное меню моделей. Предназначен для Планировщика Windows. |
| `-NoPause` | В конце работы скрипт не ждёт нажатия клавиши `Enter`. Необходимо для CI/CD и фоновых задач. |

---

## 🗑️ Параметры запуска `ollama-windows-uninstall.ps1`

Скрипт удаления принимает следующие ключи:

| Ключ | Описание |
|---|---|
| `-ConfigPath <string>` | Путь к INI-файлу. |
| `-PurgeProfile` | Удалить профиль `D:\AI\Ollama\.ollama` (включая ключ `id_ed25519`). |
| `-PurgeModels` | Удалить папку со скачанными моделями `Models\`. |
| `-PurgeOllama` | Удалить бинарники из корня `OllamaDir`. **Защищённые папки (install, OllamaTM, logs, Downloads, Backup, Models, .ollama) останутся на месте.** |
| `-PurgeLogs` | Удалить папку с логами службы `logs\`. |
| `-PurgeDownloads` | Удалить кэш скачанных архивов `Downloads\` (все версии). |
| `-PurgeBackup` | Удалить папку с резервными копиями `Backup\`. |
| `-Force` | Не запрашивать подтверждение перед удалением файлов/папок. |
| `-NoPause` | Не ждать нажатия `Enter` в конце. |

## 📄 Ключи конфигурации `ollama-windows-install.ini`

INI-файл состоит из восьми секций. Все параметры опциональны — при их отсутствии используются значения по умолчанию.

### Секция `[paths]` — Каталоги

| Ключ | По умолчанию | Описание |
|---|---|---|
| `OllamaDir` | `D:\AI\Ollama` | Корневой каталог для бинарников Ollama и данных. |
| `ModelsDir` | `D:\AI\Ollama\Models` | Каталог для скачанных моделей (OLLAMA_MODELS). |
| `NssmDir` | `C:\Program Files\NSSM` | Куда распаковывается NSSM. |
| `LogsDir` | `D:\AI\Ollama\logs` | Логи службы. |
| `DownloadsDir` | `D:\AI\Ollama\Downloads` | Кэш скачанных ZIP-архивов (`ollama_<ver>`, `nssm_<ver>`). |
| `BackupDir` | `D:\AI\Ollama\Backup` | Каталог для резервных копий бинарников перед обновлением. |

### Секция `[ollama]` — Профиль

| Ключ | По умолчанию | Описание |
|---|---|---|
| `OllamaHome` | `OllamaDir` | Домашний каталог профиля `.ollama` (содержит ключи). |

### Секция `[service]` — Служба Windows

| Ключ | По умолчанию | Описание |
|---|---|---|
| `ServiceName` | `Ollama` | Имя службы в Windows. |
| `StartType` | `SERVICE_DELAYED_AUTO_START` | Тип запуска (`AUTO_START`, `DELAYED_AUTO_START`, `DEMAND_START`). |
| `StartTimeoutSeconds` | `60` | Таймаут ожидания запуска службы (в секундах). |
| `AppRestartDelay` | `10000` | Задержка перед перезапуском после падения (в миллисекундах). |
| `AddToPath` | `true` | Добавить `OllamaDir` в переменную `PATH`. |
| `AddNssmToPath` | `true` | Добавить пути `NSSM\win32` и `NSSM\win64` в переменную `PATH`. |
| `LogRetentionDays` | `7` | Срок хранения логов службы в днях (старые файлы удаляются). |

### Секция `[network]` — Сеть и брандмауэр

| Ключ | По умолчанию | Описание |
|---|---|---|
| `Host` | `0.0.0.0` | Адрес API (0.0.0.0 - сеть, 127.0.0.1 - локально). |
| `Port` | `11434` | Порт API. |
| `FirewallEnabled` | `true` | Создавать правило брандмауэра. |
| `FirewallSubnet` | `192.168.117.0/24` | Подсеть, которой разрешён доступ (формат CIDR). |
| `Origins` | *(пусто)* | Список CORS origins (через запятую). |

### Секция `[downloads]` — Скачивание

| Ключ | По умолчанию | Описание |
|---|---|---|
| `OllamaVersion` | `ask` | Версия Ollama: `ask` (меню), `latest` (последняя), или конкретная (`0.40.10`). |
| `OllamaUrl` | *(URL)* | Резервный URL для скачивания, если GitHub API недоступен. |
| `NssmUrl` | *(URL)* | URL для скачивания NSSM. |
| `KeepDownloads` | `true` | Оставлять ли скачанные архивы в кэше после распаковки. |

### Секция `[models]` — Модели

| Ключ | По умолчанию | Описание |
|---|---|---|
| `DownloadModels` | `true` | Скачивать ли модели сразу после установки/обновления. |
| `Interactive` | `true` | Показывать интерактивное меню выбора моделей. |
| `Models` | `llama3.1:8b,qwen2.5-coder:7b` | Список моделей через запятую (для неинтерактивного режима). |

### Секция `[performance]` — Производительность

| Ключ | По умолчанию | Описание |
|---|---|---|
| `KeepAlive` | `10m` | Время удержания модели в памяти (`10m`, `24h`, `-1` — постоянно). |
| `FlashAttention` | `1` | Включить Flash Attention. |
| `KvCacheType` | `q8_0` | Тип KV-кэша (`f16`, `q8_0`, `q4_0`). |
| `NumParallel` | `1` | Количество параллельных слотов. |
| `MaxLoadedModels` | `1` | Максимум моделей в памяти. |
| `Debug` | `0` | Включить отладочные логи Ollama. |

## 🚀 Быстрый старт

1. Отредактируйте `ollama-windows-install.ini`.
2. Запустите `.\ollama-windows-install.ps1`.
3. Если Ollama уже установлена, выберите нужную версию или нажмите `s` для отмены.
