# Ollama для Windows — Установка, Обновление и Удаление

Комплект скриптов для развёртывания и обслуживания [Ollama](https://ollama.com) на Windows в виде службы через [NSSM](https://nssm.cc). Оптимизирован под **NVIDIA RTX 4060 (8 ГБ VRAM)**, но работает на любом железе с подстройкой INI.

## Состав комплекта

| Файл | Назначение |
|---|---|
| `ollama-windows-install.ini` | Единый конфиг (пути, сеть, модели, производительность) |
| `ollama-windows-install.ps1` | Установка, обновление, переустановка и логирование |
| `ollama-windows-uninstall.ps1` | Удаление службы и очистка |
| `README.md` | Этот файл (документация для GitLab) |

Все четыре файла должны лежать в одной папке — например, `D:\AI\Ollama\install`.

## Основные возможности

1. **Безопасная папка `install`.** Скрипты и лог-файл хранятся в `D:\AI\Ollama\install`. При обновлении или переустановке эта папка **никогда не удаляется**.
2. **Защищённые папки:** `install`, `OllamaTM`, `logs`, `Downloads`, `Backup`, `Models`, `.ollama` и `NssmDir` (если он внутри `OllamaDir`). Они не бэкапятся и не удаляются при обновлении.
3. **Умное обновление:** выбор версии и подтверждение происходят до остановки службы. Нажатие `s` отменяет операцию без изменений. Текущая версия помечена `(переустановка)`.
4. **Описание службы** в NSSM автоматически: «Ollama is the most popular way to build with open models...».
5. **Очистка `OllamaTM.exe`** перед обновлением/удалением.
6. **Права по SID** (`*S-1-5-18`, `*S-1-5-32-544`) — работает на любой локализации Windows.
7. **PATH для Ollama и NSSM.** Управляется флагами `AddToPath` (для `OllamaDir`) и `AddNssmToPath` (для `C:\Program Files\NSSM\win32` и `win64`).
8. **Логирование** в `ollama-windows-install.log`.
9. **Ротация логов службы** по `LogRetentionDays` (по умолчанию 7 дней).
10. **Автообновление `-Upgrade`** для Планировщика Windows.
11. **Диагностика** при неудачном старте: ExitCode, логи, `nssm dump`, прямой запуск `ollama.exe serve`.
